**Status:** Completed

A practical system administration project involving the deployment and management of an Ubuntu LXC container as a web server within a simulated company environment.

**Technologies:** Proxmox VE, Ubuntu 24.04 LTS, LXC, Nginx, OpenSSH, UFW, HTML, CSS.

**Key Implementations:**

- Linux administrator account creation and sudo permission management.
- SSH remote administration from Windows using an SSH tunnel.
- Nginx installation and service configuration.
- HTML and CSS website development for PT Digital Nusantara.
- Website deployment to the Nginx web root directory.
- UFW firewall configuration.
- SSH (TCP 22) and HTTP (TCP 80) access rules.
- Nginx service validation.
- HTTP response testing using curl.
- Website accessibility testing through a Windows browser.

**Project Results:**

Successfully deployed a website using Nginx inside an Ubuntu LXC container. The firewall was activated, HTTP returned `200 OK`, and the website was accessible through an SSH tunnel.
