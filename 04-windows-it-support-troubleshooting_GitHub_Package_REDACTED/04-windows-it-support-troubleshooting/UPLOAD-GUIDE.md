# GitHub Upload Guide

1. Download and extract this project folder.
2. Open your `it-infrastructure-portfolio` repository.
3. Upload the complete `04-windows-it-support-troubleshooting` folder.
4. Keep each section's `README.md` beside its `screenshots` folder.
5. Review the screenshots before publishing. MAC address and Product ID fields have been redacted in selected captures in this package. Review all other screenshots for any personal or sensitive information.
6. Do not mark the pending DNS failure simulation as completed until it has been performed and verified.

The root `README.md` is the project landing page. Each numbered section has its own README for focused documentation.
