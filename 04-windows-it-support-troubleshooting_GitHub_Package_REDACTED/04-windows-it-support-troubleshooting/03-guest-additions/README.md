# 03 — VirtualBox Guest Additions

## Objective
Install Guest Additions to improve integration between the VirtualBox host and Windows guest.

## Work performed
1. Inserted the VirtualBox Guest Additions CD image.
2. Opened the mounted CD in Windows File Explorer.
3. Ran the 64-bit Windows Guest Additions installer (`VBoxWindowsAdditions-amd64`).
4. Completed installation and allowed Windows to reboot.
5. Verified Oracle VM VirtualBox Guest Additions 7.0.18 in Programs and Features.
6. Verified that the guest display resolution adjusted to the VM window.
7. Set Shared Clipboard to Bidirectional and successfully copied text from the host into the guest.

## Outcome
Guest Additions installation, display adjustment, and the clipboard test were successful.
