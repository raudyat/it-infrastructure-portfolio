# 05 — Device Manager & Driver Checks

## Objective
Inspect Windows device inventory and check the reported status of key virtual devices.

## Devices observed
- VBOX HARDDISK
- VirtualBox Graphics Adapter (WDDM)
- Intel(R) PRO/1000 MT Desktop Adapter
- Intel Core i7-10870H processor entries
- High Definition Audio Device
- VirtualBox and Microsoft system devices

## Driver status checks
Opened Properties → General for the network and display adapters.

| Device | Device status |
|---|---|
| Intel(R) PRO/1000 MT Desktop Adapter | This device is working properly. |
| VirtualBox Graphics Adapter (WDDM) | This device is working properly. |

## Outcome and scope
Both checked adapters reported normal status in Device Manager. This does not certify every device or driver; only the devices shown and checked are recorded as verified.
