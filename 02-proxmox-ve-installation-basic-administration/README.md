# Proxmox VE Installation & Basic Administration

## Project Overview
This project documents my hands-on practice installing and managing Proxmox VE in a VirtualBox environment.

## Activities
- Proxmox VE installation
- Management network configuration
- Proxmox web dashboard access
- CPU, RAM, and storage monitoring
- Linux command-line administration
- Storage and network inspection
- Ubuntu VM provisioning
- Nested virtualization troubleshooting

## Platform
- Proxmox VE 9.2.2
- VirtualBox
- Windows 11

## Learning Outcomes
Developing foundational skills in virtualization, Linux administration, networking, and server infrastructure.
